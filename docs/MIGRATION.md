# 迁移对照表：静态多页 → React SPA

旧版：9 个独立 HTML（3472 行）+ 5 个 CSS + 4 个 JS + 2 个数据文件，手写导航与规则引擎。
新版：单页应用，数据与视图分离，路由级代码分割。

## 一、页面

| 旧文件         | 新路由                                                              | 变化                                                                                 |
| -------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `index.html`   | `/`                                                                 | 保留三条结论、时间轴、平台入口；统计数字改为从数据实时计算                           |
| `arm.html`     | `/arm`                                                              | 四条路线改为数据驱动（`ARM_ROUTES`）；新增平台清单表与证据等级列                     |
| `intel.html`   | `/intel`                                                            | CPU 矩阵改为读 `HARDWARE`；补 SMBIOS 四机型与 Tahoe 两个坑                           |
| `amd.html`     | `/amd`                                                              | 保留补丁链四步；「无 Hypervisor 代价」改为表格，逐项标注                             |
| `gpu.html`     | `/gpu`                                                              | 拆成 NVIDIA / AMD / Intel 三张表；NullMoth 单独成段，补性能与缺陷                    |
| `vm.html`      | `/vm`                                                               | 保留三条路线对比与直通表；项目列表改为从 `PROJECTS` 过滤                             |
| `periph.html`  | `/peripherals`                                                      | 无线、音频、有线、存储四张表；音频三方案改为卡片                                     |
| `data.html`    | `/library`、`/library/projects`、`/library/claims`、`/library/dead` | **Tab 改为子路由**（原为 `#tab=` 哈希），支持直接访问与刷新                          |
| `builder.html` | `/builder`                                                          | 重写：新增主板/插槽校验、使用方式（裸机/虚拟机/ARM）、置信度、缺失信息提示、替代方案 |
| —              | `/library/dead` 内「证据索引」                                      | 新增：全站引用的证据可逐条查阅                                                       |

## 二、交互

| 旧实现                                      | 新实现                                                   | 说明                                                      |
| ------------------------------------------- | -------------------------------------------------------- | --------------------------------------------------------- |
| `nav.js` 手写高亮 + 移动端菜单              | `NavLink` + `aria-current`，移动端菜单带 `aria-expanded` | 修复了「菜单展开后点链接不关闭」的问题                    |
| `matrix.js` 手写 DOM 渲染与筛选             | `DataTable` + `ChipGroup` + `SearchBox` 组合             | 新增排序（表头点击，带 `aria-sort`）、命中计数、空状态    |
| 哈希深链 `#tab=...&plat=...`                | 路径式 Tab + 本地筛选状态                                | 筛选不再污染 URL；Tab 可被搜索引擎索引                    |
| `rules.js`（全局 `window.RULES`）           | `src/domain/rules.ts`（ESM 纯函数）                      | 新增主板插槽校验、置信度、`unverified` 状态、缺失输入处理 |
| 复制清单用 `navigator.clipboard` + fallback | 保留，按钮有「已复制」反馈                               | —                                                         |
| 无                                          | 配置状态写入 URL                                         | 可分享、可前进后退                                        |

## 三、数据

| 旧结构                                                                    | 新结构                                                    | 变化                                         |
| ------------------------------------------------------------------------- | --------------------------------------------------------- | -------------------------------------------- |
| `hw.js`：`matrix`（51 行扁平表）+ `cpus/gpus/wifi/audio/arm` 五套并列数组 | `hardware.ts`：**65 条统一记录**，矩阵是它的视图          | 消除同一硬件在多处维护的风险                 |
| `projects.js`：`list` + `dead` + `corrections`                            | `projects.ts` + `claims.ts`                               | 新增 `codeOpen` / `reproducibility` 两个维度 |
| 无证据字段                                                                | 每条记录挂 `evidenceIds`，`evidence.ts` 统一登记          | 新增 43 条证据，含版本、核验日期、失效标记   |
| 无结论台账                                                                | `claims.ts`：30 条带 ID 的结论                            | 配置生成器可直接引用 `C-0xx`                 |
| 无主板数据                                                                | `boards.ts`：10 条主板/插槽                               | 生成器可判断插槽不匹配                       |
| 规则里用字符串比较（`level === 'none'`）                                  | 判别式字段：`gpu.driver`、`cpu.flags[]`、`arm.bootMethod` | 分支语义明确，新增型号不需要改规则           |

## 四、工程

| 项目   | 旧                      | 新                                                                                   |
| ------ | ----------------------- | ------------------------------------------------------------------------------------ |
| 构建   | 无（手写 HTML）         | Vite 8，产物 21 个文件，首屏 JS 137KB gzip                                           |
| 类型   | 无                      | TypeScript strict，`noUncheckedIndexedAccess` + `exactOptionalPropertyTypes`         |
| 校验   | 无                      | Zod 运行时校验 + 证据引用完整性检查（启动即执行）                                    |
| 测试   | 13 条 Node 断言（规则） | 35 条 Vitest（规则 24 + 组件 11）+ 30 条 Playwright                                  |
| Lint   | 无                      | ESLint 9 flat config + Prettier                                                      |
| CI     | 无                      | GitHub Actions：typecheck → lint → format → test → e2e → build → 子路径自检 → deploy |
| 字体   | 6 档 870KB              | 3 档 420KB，构建期预载 400/600                                                       |
| 深链接 | 多页天然支持            | SPA + `404.html` 兜底（构建时生成）                                                  |
