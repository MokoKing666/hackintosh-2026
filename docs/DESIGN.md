## ② 六态语义色

**编码原则**：色相只做冗余通道。灰度下靠 **字形 + 填充浓度 + 边框线型** 三重区分；**状态列必须始终输出文字标签**，颜色与字形是加速器而非唯一载体。

| 结论枚举   | 字形 | 文字色    | 底           | 边框                 | 灰度特征            |
| ---------- | ---- | --------- | ------------ | -------------------- | ------------------- |
| 已验证可用 | ✓    | `#14683C` | `#E9F4EE`    | `1px solid #A9D5BC`  | 淡底 + 实线 1px     |
| 有条件可用 | ◐    | `#8A5A00` | `#FBF1DC`    | `1px solid #E2C286`  | 淡底 + 半填充字     |
| 实验性支持 | ○    | `#5B3AA8` | `#F1EDFB`    | `1px dashed #C4B4E8` | 淡底 + **虚线**     |
| 尚未验证   | □    | `#4A4A4F` | 无（`--bg`） | `1px solid #C9C9CE`  | **无底** + 空心方   |
| 已知不兼容 | ✕    | `#A32B1F` | `#FBEAE7`    | `2px solid #E5A79E`  | 淡底 + **2px 粗边** |
| 信息不足   | ⋯    | `#6E6E73` | 透明         | `1px dotted #D8D8DD` | **无底** + 点线     |

**深色段（`--bg-deep` 作用域内）**：文字 `#6FD79B` / `#E8B25C` / `#B79BFF` / `#C7C7CC` / `#F08A7C` / `#8E8E96`；底一律为对应色的 `12%` 透明；边框为 `32%` 透明或 `#3A3A42`（无底两态）。

**关键取舍**

- 「尚未验证」= 空心方 + 实线 + 中性灰；「信息不足」= 点线 + 更浅灰 + 无底。两者都 **不填任何暖色/警示色**，且都没有 ✓/✕/△ 类判断性字形——它们是「无结论」，不是「坏结论」。
- 「已知不兼容」用 2px 边框而非更深红底：红底在灰度里会与「已验证」的绿底撞成同一块中灰，粗边是灰度下唯一稳定的强度信号。
- 对比度全部 ≥ 5:1（AA 小字），实测：6.08 / 5.28 / 6.96 / 8.81 / 6.17 / 5.07。

## ③ 证据等级编码

不用 6 个颜色。用 **4 格强度条 + 单字母码**，单色（`--fg`），12×10px，条宽 2px、间隙 2px、无圆角。

| 等级       | 码  | 强度条 | 灰度读法                         |
| ---------- | --- | ------ | -------------------------------- |
| 官方文档   | A   | ▮▮▮▮   | 4 格实心 = 满                    |
| 上游代码   | B   | ▮▮▮▯   | 3 格                             |
| 可复现测试 | C   | ▮▮▯▯   | 2 格                             |
| 社区报告   | D   | ▮▯▯▯   | 1 格                             |
| 项目方声明 | E   | ▯▯▯▯   | 4 格**空心**描边（1px, 30% ink） |
| 推断       | F   | 斜纹块 | 4px 45° hatch, 18% ink           |

**为什么 E/F 不进同一根轴**：A–D 度量的是「可被第三方验证的程度」，E（利益相关方自述）与 F（无来源推导）是 **来源性质** 不同，不是强度更低。空心描边与斜纹在视觉语法上就宣告「这不是刻度上的一个位置」。

**用法**：表格中占 16px 宽固定列，仅显示强度条；字母码以 mono 11px 跟在后面（可选，紧凑模式下隐藏）。`title` 与 `aria-label` 承载全称。图例在表格头部出现一次，不做逐行解释。

| 表格字号     | `--fs-table` 13px/1.4；标识符与版本列 `--font-mono` 12.5px + `tabular-nums`，右对齐                                 |
| 状态列       | 12px/500 徽章，高 20px，内距 `0 6px`，`--r-xs`                                                                      |
| 证据列       | 固定 16px 宽，强度条垂直居中                                                                                        |
| 行分隔线     | 仅横向 `1px solid --border`；**无竖线**、**无斑马纹**                                                               |
| 行交互       | hover `--bg-subtle`；选中 `--accent-weak` + 左缘 `2px solid --accent`                                               |
| 首列         | sticky `left: 0`，`z-index: 210`，右缘 `1px solid --border`，`--bg` 实底（hover 时同步变色）                        |
| 横向滚动阴影 | 容器 `position: relative`；首列右侧 `24px` 渐变 `rgba(0,0,0,.06) → transparent`，仅在 `scrollLeft > 0` 时挂载 class |
| 筛选栏       | 高 `44px`；chips 高 `24px`、`--r-sm`、`12px/500`；与表头间距 `--sp-3`                                               |
| 排序         | 表头右侧 8px 三角标，`--fg-3`；激活态 `--fg` + `600`                                                                |
| 虚拟化       | 86 行即需窗口化；行高固定是前提，故 `32/36px` 二选一而非自适应                                                      |
| 空态         | 表格区保留表头，内容区 `160px` 高居中空态文案 + 清除筛选按钮                                                        |
| 加载态       | 8 行骨架，行高与真实行一致，`--bg-subtle`，无 shimmer 动画                                                          |

**移动端（<720）：选卡片化，不做横滑表格。**

理由：本表 6–9 列，其中 4 列是版本号/参数类长文本，横滑需要 3–4 屏宽；同时 sticky 首列会吃掉窄屏 40% 宽度，与横向滚动在触屏上还会和纵向页面滚动抢手势。卡片化信息损失更小。

卡片规格：单卡高 `~120px`，内距 `--sp-3`，`1px solid --border`，`--r-md`，无投影。卡内结构 = 标题（16px/500，版本号 mono 12px 跟在后面）+ 六态徽章 + 证据条 + 3 个关键字段的 2 列网格（`11px` 标签 / `13px` 值）。保留筛选栏（改为底部抽屉）与排序（改为一个 select）。卡片密度可切舒适/紧凑（`120px` / `96px`），列表窗口化。

## ⑥ 克制红线

1. **禁止渐变文字与渐变遮罩标题**。强调只用字重、字号、字色；大标题不允许 `background-clip: text`。
2. **禁止多级投影**。全站只有两个 elevation：sticky 表头的 `0 1px 0`、浮层的 `0 4px 16px`。表格、卡片、徽章、按钮默认零投影，层级靠边框与底色表达。
3. **禁止玻璃拟态用于任何数据界面**。`backdrop-filter` 不得出现在表头、筛选栏、表格容器、卡片上。
4. **禁止纯色相编码**。六态与六级证据都必须带字形/强度条 + 文字标签；任何「只靠红绿蓝区分」的实现一律驳回。
5. **禁止等宽字体越界**。`--font-mono` 仅用于版本号、标识符、路径、证据码、数字列；正文、标题、按钮、导航一律 sans。中文正文禁止 `letter-spacing`。
6. **禁止营销语与状态 emoji**。不用感叹号、不用「最强/完美/一键」；状态图标只用几何字形（✓ ◐ ○ □ ✕ ⋯），不用 emoji。

## ⑦ 字体加载策略（870KB 六个字重）

**结论：砍到 3 个字重（400 / 500 / 600），约 430KB；200 与 700 删除，300 不引入。** 现有字号表只用到 400/500/600，200/300/700 属于为「可能用到」付出的首屏代价，且 200 在 16px 以下中文里不可读。

| 字重            | 加载方式                                                                | `font-display` | 理由                                    |
| --------------- | ----------------------------------------------------------------------- | -------------- | --------------------------------------- |
| 400             | `<link rel=preload as=font type=font/woff2 crossorigin>` + 首屏关键子集 | `swap`         | 正文，首屏必需                          |
| 600             | 同上，preload                                                           | `swap`         | 标题与表头，首屏必需（ABOVE-FOLD 标题） |
| 500             | 懒加载（首次渲染后注入 `@font-face`，或 `media="print" onload` 技巧）   | `swap`         | 仅 h3 与徽章，晚 1 帧无感               |
| 200 / 300 / 700 | **删除**                                                                | —              | 未被使用                                |

补充：

- 中文按 `unicode-range` 分「常用 1500 字 / 其余」两片，首屏只 preload 常用片。
- 回退栈做度量对齐（`size-adjust` / `ascent-override`）匹配 `-apple-system`，避免 swap 造成 CLS。
- **等宽字体不下载文件**，用系统栈（`ui-monospace` / `SF Mono` / `Menlo`）。这是把 6 个字重压到 3 个之外的第二笔省下的体积。
- `font-display` 不用 `optional`：本站正文是核心内容，宁可 swap 也不能让首屏落回系统字体后再跳。
