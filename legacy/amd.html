AMD

用补丁换来的性能

AMD 平台的性价比一直很有说服力：同样的钱买到更多核心，Zen3 至今是最成熟的非 Intel 方案。 代价不在装的时候，而在装完之后——你会发现某些东西永远用不了。

补丁链

AMD_Vanilla 做的四件事

它不是「让 macOS 支持 AMD」，而是把 macOS 内核里那些假定「我是 Intel」的指令一条条改掉。 补丁集合由 AMD-OSX 维护，3108 star，2025-12 之后节奏放缓。

  1. 改 CPUID 与核心数
    补丁里有一个 _cpuid_set_info 的替换块， 需要按你的物理核心数改最后一位（8 核写 08，12 核写 0C）。 改错会直接卡在启动早期。
  2. 补 MSR 与电源管理
    绕开 Intel 专有的 MSR 读写，改走 AMD 的等效路径。VirtualSMC 在这之上再模拟一层 SMC。
  3. Zen4 额外打 IOPCIFamily 补丁
    这一条同时修好 MSI 的 A520 / B550 / X570 主板，Zen4 平台默认启用。
  4. Zen5 需要 OpenCore ≥ 1.0.2
    靠 AMD_CPU_EXT_FAMILY_1AH 支持。 注意：公开案例很少，社区把它归在「验证中」，不是「成熟」。
代际 代表型号 补丁状态 核显 建议
Zen 2 / Zen 3 R5 3600 / R5 5600 / R7 5800X3D 成熟 无核显（或 Vega，见下表） 首选。案例最多，踩坑最少
Zen 4 R7 7700X / R7 7800X3D / R9 7950X 需额外补丁 610M 无解 要加 IOPCIFamily 补丁，注意 DDR5 平台的内存兼容性
Zen 5 R9 9950X / R7 9800X3D 验证中 无解 需 OC ≥ 1.0.2，公开案例少，不建议当第一台
Threadripper 3970X (TRX40) / 7960X (sTR5) 需补丁 无 TRX40 可关掉两条 PAT patch 提升 GPU 性能

关于 Zen5：AMD_Vanilla 主仓库里没有任何 Zen5 专用补丁，最近一次 Zen 相关 PR 是 2023 年的 IOPCIFamily 修正。 所以「Zen5 能装」依赖的是 OpenCore 侧的 CPU 家族识别，而不是 Vanilla 的补丁。

代价

没有 Hypervisor，等于半个生态断掉

AMD 补丁绕过了 Intel 的虚拟化指令，代价是 macOS 的 Hypervisor.framework 起不来。 这不是「虚拟机慢一点」，是直接不可用。

依赖项 状态 说明
Docker Desktop 不可用 Linux 容器需要 HVF，只能退回远程 Docker 或 Colima 的远程模式
Parallels Desktop 不可用 启动即报错
VMware Fusion 不可用 同上
Android 模拟器（AVD） 无硬件加速 能跑但慢到不可用
Adobe 部分组件 需额外 patch Lightroom、部分 GPU 加速路径
FairPlay / Apple TV+ 依赖独显 需免驱 A 卡，核显不行
先问自己一句：你平时开不开 Docker？如果开，AMD 平台基本可以排除， 除非你愿意把容器全放到另一台机器上。

APU 核显

断代非常干净：Vega 可以，RDNA 不行

NootedRed 是目前唯一能让 AMD 核显出画面的项目，2000 star，2026-10 仍在维护。 但它只覆盖 GCN / Vega 一代，再往后就断了。

Vega 3 / 6 / 8 / 10

Raven Ridge、Picasso、Renoir、Cezanne、Barcelo 的核显全部覆盖。 5800H 在 26.7.1 上有 fork 做到「近乎完美」——硬件解码、亮度、花屏三项全修。

需 NootedRed v0.8.10

660M / 680M（RDNA 2）

至今无解。2026 年社区的所有进展都在 Vega 上，RDNA2 核显连 bring-up 都没有公开记录。 搭载这类核显的轻薄本只能靠独显输出。

无解

740M / 760M / 780M（RDNA 3）

同样无解，但 2026-10 出现了 nullarc（55 ★）在 Tahoe 上做 780M 的 Metal / WindowServer bring-up。属于研究性质，离能用很远。

无解 有实验

一个容易忽略的细节：NootedRed 的 README 上挂着「written by humans, not AI」徽章， 并在 2026-10-10 换成了 ChefKiss Open Knowledge License v1，明文禁止用于训练或配合 AI。 这个圈子里，「谁写的」本身已经成了立场问题。
