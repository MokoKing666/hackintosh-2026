显卡

N 卡回来了，
但只有十分之一的力气

2026 年最意外的事：被 Apple 判死七年的 NVIDIA，被一个独立开发者用三周时间救活了。 GTX 16 到 RTX 50 全系能点亮、能跑 Metal——只是性能只有 Windows 的十分之一。

主角

NullMoth：把 Metal 架在 NVIDIA 的开源内核模块上

它不是重写驱动，而是绕路：让 Metal 应用以为自己在跟 Apple 的驱动说话， 中间一层翻译器把 Apple 的 AIR 中间表示转成 SPIR-V，交给 Mesa 的 NVK， 再由 NVIDIA 开源的 r610 内核模块落到硬件上。

能装什么

Turing 及更新：GTX 1650 / 1660 系、RTX 20 / 30 / 40 / 50 全系、TITAN RTX、 Quadro RTX 与 T400–T1200、RTX A 系。设备表共 247 个 PCI ID，取自 NVIDIA 615.78.08 驱动。

系统侧：驱动本体支持 macOS 15.5 起与 26 Tahoe；但配套的一键安装器 1401 目前把系统锁在 15 Sequoia。 想上 Tahoe 要手动装，并注意 Tahoe 黑屏的 bug 在 v1.14 才修。

要改什么

boot-args:
  nvfb=1 nvaccel=1 nvfbheads=4
  -nvkmsnosmooth amfi=0x80
  amfi_get_out_of_my_way=0x1
  ipc_control_port_options=0

csr-active-config   = 430A0000
SecureBootModel     = Disabled
Kernel → Block      = IONDRVSupport
kext                = Lilu + AMFIPass
装 WhateverGreen 时 加 gfxrst=4

性能实测（社区数据，非官方基准）

RTX 3060 · Windows 700 帧
RTX 3060 · macOS 60 帧

同一台机器、同一个 Minecraft 整合包。另有多份反馈：4K 与 1080p 能到 160Hz， 1440p 只有 60 帧；Geekbench Metal 跑分超过 90000，媒体表述为「约等于标准版 M1」， 但这个数字与官方基准口径不一致，只能当参考。

别当生产力用。没有硬件编解码，YouTube 高码率视频会吃满 CPU，达芬奇直接报错； 双 4K 会黑屏；HDMI 音频针脚还在修；安全研究者已经在这套驱动里挖出过几处漏洞， 开发者随后修了一轮。能跑，不等于可靠。

官方线

Apple 那边的四代结局

第三方驱动是补救，不是翻案。按 Apple 自己的支持线，N 卡在 macOS 上的历史是这样断掉的。

≤ 10.13.6

Kepler / Maxwell / Pascal 都还能用

靠 NVIDIA 的 Web Driver，GTX 10 系在 High Sierra 上是完整可用的。

10.14

Mojave 起 Web Driver 断绝

NVIDIA 未再发布新驱动。GTX 10 系从此停在 High Sierra，往后只能靠 OCLP 打补丁点亮，没有 Metal。

11

Kepler 被移出内核（Monterey beta 7 完成）

GTX 680 / 780 / TITAN 这一代反而活得久，OCLP 补丁能带到 Sequoia 15，并且保留 Metal。

12 – 26

Turing / Ampere / Ada 官方「None」

Dortania 的显卡指南里，这一栏长期写着 Highest Supported OS: None。直到 2026-10 才被第三方改写。

A 卡

AMD 仍是免驱主力，但上限卡在 Navi 2x

型号 架构 状态 需要的参数 / kext 备注
RX 570 / 580 Polaris 免驱 — 只有 Metal 2，无 Metal 3；避开 XFX / PowerColor / HIS / VisionTek
RX 5700 / 5700 XT Navi 10 免驱 agdpmod=pikera 不加参数容易黑屏
RX 6600 / 6600 XT Navi 23 免驱 agdpmod=pikera 性价比最高的选择
RX 6800 XT / 6900 XT Navi 21 免驱 agdpmod=pikera 6950 XT 需伪装成 6900 XT
RX 6700 / 6750 Navi 22 需 kext NootRX.kext Apple 从未支持这一档
RX 7600 / 7800 XT / 7900 XTX Navi 3x 无解 — Dortania：Apple 不再产 Intel Mac，未来几乎不可能加入

Tahoe 特别注意：WhateverGreen 在 macOS 26 上会引发 panic，官方建议整个移除， agdpmod=pikera 改用手工 Kernel → Patch 注入。

Intel 核显

两条实验线，一条为旧架构，一条为新架构

WhateverXe 走的是「给老架构补驱动」的路，覆盖到 Raptor Lake-P； XeGfx 走的是「把 Linux 驱动搬过来」的路，瞄准 Meteor Lake 之后的 Xe-LPG / Xe2。

两条线的共同代价是 FairPlay 失效——受保护的视频内容放不了。

看 Intel 平台的完整拆解 →

WhateverXe 0.6.1 + 图形包 0.3.2

Tiger Lake-U、Alder Lake-N、ADL-H、ADL-S 的 UHD 770、ADL-P / RPL-P。 需要已签名图形包、SIP 0x803、AMFIPass v1.4.1 Mod。最多 3 屏。

XeGfx 0.0.46

Arrow Lake-S/HX 与 Meteor Lake 已跑通，实测 26.7.1 / 26.7.2。 把 FreeBSD 的 i915 搬进 XNU，配 Mesa ANV 做 Metal-to-Vulkan。有未决 panic。
