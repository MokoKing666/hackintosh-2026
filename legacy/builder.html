        规则

        生成器背后的四条硬约束

        它不会给出「Navi 3x + macOS 27 可行」这种结论，因为下面四条是前置闸门，不是并列建议。

        ① 平台闸门

        Intel / AMD 的系统上限写死 26.7.x；ARM 按具体设备给上限， Snapintosh 到 27、RK3588 到 27.2 Beta，骁龙 X Elite 与 N1x 直接判不可行。

        ② 版本闸门

        目标系统超过上限就阻断。macOS 27 对 x86 是硬阻断，不是「可能有问题」。

        ③ 图形互斥

        独显优先于核显。Navi 3x、RDNA3 APU、Intel Arc 直接阻断； N 卡走 NullMoth 分支时，会额外检查 ReBAR、BAR 尺寸与 IONDRVSupport。

        ④ 冲突扫描

        AMD CPU × N 卡的 PAT 冲突、Tahoe 必须移除 WhateverGreen、 AppleHDA 移除后的音频三选一，都在这一步触发。

        被判「装不了」也别急着关页面：如果只是想在 macOS 里跑 Xcode 或做测试， 在 x86 宿主上用 QEMU/KVM 起一台虚拟机就够了，不需要任何兼容硬件。 见 虚拟机 / KVM 篇。

        规则依据

        1. 系统边界：WWDC26 与 MacRumors 2026-09-25 报道，OCLP 团队无 macOS 27 适配计划。
